# Durable Lessons

`.agents/learnings.md` holds concise facts learned from real work.

Add a lesson only when it is reusable, evidenced, and likely to prevent a future mistake. Each entry
must include a date, scope, the durable rule, and the evidence path/test. Do not store task status,
speculation, prompts, credentials, customer data, or private issue content.

Promote a lesson only after the same rule has independent evidence twice. Move it into the canonical
routed playbook and remove the duplicate from the lesson log. Correct stale guidance explicitly
rather than appending a conflicting rule.
