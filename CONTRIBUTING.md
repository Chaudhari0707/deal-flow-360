# Team Development

1. Read `AGENTS.md` and the current Linear issue.
2. Check active claims, branches, worktrees, and shared-file ownership.
3. Create `agent/<linear-id>-<slug>` from current `origin/main`.
4. Implement only the owned acceptance criteria and keep unrelated work intact.
5. Run focused checks while iterating and `bun run check` before handoff.
6. Use `.github/PULL_REQUEST_TEMPLATE.md` and report actual verification and demo steps.

For work moving between devices, use the claim and handoff templates in
`.agents/coordination.md`. Automated deployment pipelines and additional approval stages are not
part of the hackathon workflow.
